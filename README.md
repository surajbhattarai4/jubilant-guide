# 🍽️ FoodHub - Digital Restaurant Menu

A modern, fully-functional one-page digital menu website that customers can access by scanning a QR code. Perfect for restaurants, cafes, and food delivery services.

## ✨ Features

### Customer Features
- 📱 **Mobile-First Responsive Design** - Works seamlessly on all devices
- 🔍 **Search Functionality** - Instantly search menu items
- 🏷️ **Category Filtering** - Browse by food category (Burgers, Pizza, Chicken, etc.)
- ⭐ **Advanced Filters**
  - Filter by Veg/Non-Veg
  - Filter by Popular items
  - Filter by Price range
- 🛒 **Shopping Cart** - Add/remove items, adjust quantities
- 💳 **Checkout System**
  - Customer information collection
  - Table number tracking
  - Special notes/instructions
- 📋 **Order Summary**
  - Complete order details
  - Share via WhatsApp
  - Copy to clipboard
  - Print order receipt

### Admin Features
- 🔐 **Password-Protected Admin Panel** (Password: `admin123`)
- 🏪 **Restaurant Information Management**
  - Update restaurant name
  - Update welcome message
- ➕ **Add Menu Items**
- ✏️ **Edit Menu Items**
- 🗑️ **Delete Menu Items**
- 💾 **Local Storage** - All data persists locally

### Technical Features
- 📲 **QR Code Generation** - Generate QR codes for menu sharing
- 💾 **Works Offline** - After first load
- 🎨 **Modern UI/UX** - Clean professional design
- ♿ **Accessibility** - WCAG compliant
- ⚡ **Performance Optimized**

## 🛠️ Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage API
- QRCode.js

## 📁 Files

- `index.html` - Main HTML structure
- `style.css` - Styling and responsive design

## 🚀 Getting Started

### Online (GitHub Pages)
1. Navigate to repository settings → Pages
2. Select "Deploy from a branch"
3. Choose "main" branch and "/" (root) folder
4. Save and wait 1-2 minutes for deployment

### Local
1. Clone the repository
2. Open `index.html` in any web browser
3. No build process needed!

## 📖 Usage Guide

### For Customers
1. Scan QR Code to access the menu
2. Browse and filter items
3. Add items to cart
4. Proceed to checkout
5. Share order via WhatsApp or print

### For Admins
1. Click ⚙️ button (bottom right)
2. Enter password: `admin123`
3. Manage restaurant info and menu items

## 🎨 Customization

Edit `script.js` to change:
- Default menu items
- Restaurant name
- Admin password
- Colors and styling in `style.css`

## 🔒 Security Note

**Change the admin password before deploying!**
Default: `admin123`
